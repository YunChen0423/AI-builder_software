# AirPause · 气间 v0.6.0

Apple Silicon/macOS 13+的桌面工作与休息提醒应用。菜单栏、三气囊形象、全屏穿透烟花和音乐响应。

## 构建与启动

需Xcode Command Line Tools（Swift工具链）和Python3，无第三方运行依赖。

```sh
./test.command
./build.command
open "build/气间 AirPause.app"
```

也可双击`打开气间.command`。首次构建生成原创试听音乐及图标；build产物和合成WAV不纳入Git。构建只作本机临时签名，尚未为跨Mac分发公证。

详细操作见[中文说明](README_中文.md)。所有气量/RGB均为软件模拟目标，**尚未连接真实泵、阀或LED**。默认关闭的TCP JSONL开发接口见[硬件接口](Docs/硬件接口.md)，不能直接控制另一仓库的AIRLIGHT固件。
