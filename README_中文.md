# 气间 AirPause · v0.6.0

一个安静工作、尽兴休息的桌面三气囊形象。macOS 13+ / Apple Silicon。

双击「打开气间.command」启动。启动后没有主窗口，只有菜单栏的风形图标。

- **气囊周围的大区域右键**：打开「结束休息／偏好设置／退出气间」菜单，不需要点中气囊。区域包含周围留白，并保留最近约 1.8 秒的位置，移动后原处也能点。普通左键点击继续穿透。
- **悬停不再暂停**：不做悬浮时长或主动靠近判断；只有控制菜单打开时暂时定住，关闭菜单后继续。
- **菜单栏风图标**：左键菜单中也可打开设置，右键可直接打开单页偏好。
- **左键菜单栏图标 → 现在休息一下**：立即播放音乐并体验。
- **左键菜单栏图标 → 结束休息**：一起收起气囊和满屏烟花，停止内置／本地音乐。也可延后 5 分钟或暂停提醒。
- 休息时气囊大幅收缩、膨胀、摇摆、跳动，在整片桌面游走。拖动后停留 15 秒。
- 烟花有径向扩散、旋转流场、波纹叠层、几何散射等抽象组合，铺满所有连接的显示器；烟花层不会挡住鼠标点击。
- 工作时形象和烟花完全隐藏。默认活跃工作 45 分钟后提醒休息 3 分钟。

电脑活跃时长用于当前工作检测，不等于检测到真实手腕。键鼠最近 60 秒内有活动才累计，离开 5 分钟清零；睡眠、锁屏后清空本轮计时。没有开机自启动。

音乐支持内置原创 100 BPM 循环、本地音频、Apple Music、网易云和 Spotify。外部播放器需要在选择后允许自动播放控制、连接系统音频；首次登录和选曲可能需要手动完成。系统音频只用于分析音乐能量，不保存音频或屏幕，也不使用麦克风。外部播放器的音量和停止由用户控制。

所有气囊百分比与 RGB 仍是软件模拟目标；本次修改不接入或驱动真实气泵、灯带。硬件接口保留在代码中，见 `Docs/硬件接口.md`；日常偏好里不显示设备控制台。

开发：`./build.command` 构建，`./test.command` 验证状态机。无第三方依赖。`--smoke` 检查安静启动、满屏可穿透烟花、播放与结束隐藏；`--snapshot` 导出单页偏好和视觉效果截图到 `/tmp/airpause-*-v2.png`。本机临时签名，未做跨 Mac 分发公证。

烟花风格：随机组合、径向脉冲、旋涡流场、波纹叠层、几何散射。展开「几何参数」可选光点、线段、圆弧、棱片或混合元素，并调整扩散、旋转、密度和拖尾；没有爱心等具象轮廓。运动方式：蹦蹦跳跳、绕圈飞舞、左右冲刺、轻盈漂浮、原地起舞。都在单页偏好面板中即时切换并自动保存。

材质采用乳白磨砂 PVC 的透光外壳、细微磨砂颗粒和焊接边，叠加鲜亮的 LED 色光。四组配色为电光紫、炽热橙、酸性绿与 RGB 霓虹。桌面的「气间 AirPause.app」是指向此构建的快捷链接，更新项目后不需要重新创建。运行中再次打开应用会显示偏好设置。

三气囊改为圆润的圆角枕状。渲染画布扩展并根据变形后的完整轮廓预留光晕边距，透明留白会穿透鼠标点击。音乐联动分析真实 PCM 的能量、低频、高频与突发起音，驱动颜色流动、跳跃、摇摆、充放气和游走速度。内置／本地音频在后台按实际播放位置读取短窗口，外部音乐使用系统音频输入；无声音时仅保留轻缓呼吸，不伪造强节拍。

v0.5.1：缩小中央气囊，使用半圆端部的圆润枕状轮廓；三块充满时的视觉面积接近，音乐充放气时仍会各自变化。

v0.6：三块气囊改为相近大小的柔软鼓包，轻微重叠并有连接焊边。收敛外部光晕，采用内部色光、细磨砂和柔和高光塑造体积。

事件实现参考 Apple [Monitoring Events](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/EventOverview/MonitoringEvents/MonitoringEvents.html) 与 [NSMenu popUp](https://developer.apple.com/documentation/appkit/nsmenu/popup(positioning:at:in:))。
